# Employee Salary Management System

A web-based application for managing employee records, salaries, and employee-related information through a simple and user-friendly interface.

## Live Demo

[View Live Project](https://employee-salary-management-system-f.vercel.app/)

## Features

- User registration and login
- Admin and Employee role-based access
- Employee management (Add, Update, Delete, View)
- Employee search and pagination
- Salary management
- Employee profile management
- Employee and salary analytics
- JWT-based authentication
- Responsive user interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- JWT
- Git & GitHub
